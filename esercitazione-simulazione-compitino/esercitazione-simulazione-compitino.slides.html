function f(a, b) {
    if (a > b) return a - b;
    return b - a;
}

OpzioneRisposte

Soluzione: 5 5

f restituisce sempre la differenza positiva tra i due numeri.

  • f(3, 8): 3 > 8 è falso, si arriva al secondo return e si calcola 8 - 3 = 5

  • a + b con a stringa: + fa la concatenazione, quindi "5" + 3 è "53"

Modulo A - Esercizio 2: funzioni

Definire due funzioni:

  • isMultiplo(a, b): true se a è multiplo di b, false altrimenti
  • sommaMultipli(N, k): somma dei multipli di k tra 1 ed N (estremi inclusi), usando isMultiplo

Nel programma principale: leggere N e k, chiamare sommaMultipli, stampare il risultato e stampare se è pari o dispari (usando ancora isMultiplo).

Esempio (N = 10, k = 3):

Somma dei multipli di 3 fino a 10: 18
Il risultato è pari

Modulo A - Esercizio 2: soluzione

function isMultiplo(a, b) {
  return a % b === 0;
}

function sommaMultipli(N, k) {
  let somma = 0;
  for (let i = 1; i <= N; i++) {
    if (isMultiplo(i, k)) {
      somma += i;
    }
  }
  return somma;
}

let N = Number(prompt("N:"));
let k = Number(prompt("k:"));
let risultato = sommaMultipli(N, k);
console.log("Somma dei multipli di " + k +
  " fino a " + N + ": " + risultato);
let tipo = isMultiplo(risultato, 2) ? "pari" : "dispari";
console.log("Il risultato è " + tipo);

Modulo B - Domanda 2: soluzione

Menu 1Risposte

Per contare le persone in almeno un corso non basta sommare le dimensioni: chi segue più corsi viene contato più volte. Si usa il principio di inclusione-esclusione:

|M∪F∪I| = |M| + |F| + |I| − |M∩F| − |M∩I| − |F∩I| + |M∩F∩I|

  1. si sommano i tre insiemi: 42 + 35 + 30 = 107
  2. si tolgono le intersezioni a coppie (chi è in due corsi era contato due volte): 107 − 15 − 12 − 10 = 70
  3. si riaggiunge la tripla intersezione: chi segue tutti e tre i corsi è stato contato 3 volte al passo 1 e tolto 3 volte al passo 2, quindi ora non compare più: 70 + 6 = 76

70 (13%) è l'errore tipico: ci si ferma al passo 2. Il totale di 90 iscritti non serve.
