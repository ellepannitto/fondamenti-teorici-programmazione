Recap 1 · Gli array

Finora ogni variabile conteneva un solo valore (uno scalare). Un array è una oggetto che contiene più valori in fila, come una scatola con tanti scomparti numerati.

let città = ["Roma", "Firenze", "Pisa", "Lucca"];
let voti = [28, 30, 25];
let pippo = [];                                 // array vuoto: nessun elemento

Ogni elemento ha un indice, cioè la sua posizione. Si parte da zero:

indice0123
città"Roma""Firenze""Pisa""Lucca"
console.log(città[0]);                          // Roma: il primo elemento
console.log(città[2]);                          // Pisa
città[1] = "Siena";                             // cambia il valore dell'elemento in posizione 1
console.log(città);                             // [ 'Roma', 'Siena', 'Pisa', 'Lucca' ]

La lunghezza dell'array (il numero di elementi) si ottiene con length, senza parentesi:

console.log(città.length);                      // 4
console.log(città[città.length - 1]);           // Lucca: l'ultimo elemento
console.log(città[4]);                          // undefined: la posizione 4 non esiste

Con length elementi gli indici validi vanno da 0 a length - 1. Leggere fuori da questo intervallo non dà errore: dà undefined.

Assegnare a una posizione oltre la fine, invece, allarga l'array: le posizioni intermedie restano vuote e la lunghezza diventa (indice più grande usato) + 1.

let pippo = [];
pippo[2] = 5;                                   // oltre la fine: l'array si allarga
console.log(pippo.length);                      // 3: le posizioni 0 e 1 restano vuote
console.log(pippo[0]);                          // undefined: leggendole si ottiene undefined
console.log(pippo);                             // [ <2 empty items>, 5 ]

Le posizioni vuote sono dei «buchi»: non contengono il valore undefined, semplicemente non esistono come elementi (per questo console.log scrive <2 empty items>). Leggerle però dà undefined, come per qualsiasi posizione fuori dall'array.

Per aggiungere un elemento in fondo si assegna alla posizione length, che è la prima ancora libera:

let v = [4, 7];
v[v.length] = 9;                                // v.length vale 2: si assegna alla posizione 2, in fondo
console.log(v);                                 // [ 4, 7, 9 ]

Per scorrere un array si usa un ciclo for con l'indice come contatore:

let voti = [28, 30, 25];
for (let i = 0; i < voti.length; i++) {         // i vale 0, 1, 2: si ferma prima di length
  console.log("voto", i, "=", voti[i]);
}

Recap 2 · Array e funzioni

Un array può essere parametro di una funzione, e una funzione può restituire un array.

function somma(v) {
  let s = 0;
  for (let i = 0; i < v.length; i++) {
    s = s + v[i];
  }
  return s;
}

console.log(somma([1, 2, 3, 4]));               // 10
console.log(somma([]));                         // 0: array vuoto, il ciclo non parte

C'è però una differenza importante rispetto ai numeri. Quando si passa un numero a una funzione, la funzione riceve una copia: cambiarla dentro non tocca l'originale. Quando si passa un array, la funzione riceve lo stesso array (non una copia): se lo modifica, la modifica si vede anche fuori.

function raddoppia(v) {
  for (let i = 0; i < v.length; i++) {
    v[i] = v[i] * 2;                            // modifica l'array originale!
  }
  return v;
}

let a = [1, 2, 3];
let b = raddoppia(a);
console.log(a);                                 // [ 2, 4, 6 ]: a è cambiato, anche se non volevamo

Lo stesso succede con l'assegnazione =: non copia l'array, crea solo un secondo nome per lo stesso array.

let a = [1, 2, 3];
let b = a;                                      // b e a sono lo STESSO array
b[0] = 100;
console.log(a);                                 // [ 100, 2, 3 ]

Per avere una copia vera si può usare let b = [...a]; oppure let b = a.slice();.

La nostra regola: una funzione non modifica mai l'array che riceve. Se deve produrre un array, ne costruisce uno nuovo (partendo da []) e lo restituisce. Così l'array di partenza resta com'era e non ci sono sorprese.

function raddoppia(v) {
  let risultato = [];                           // array nuovo
  for (let i = 0; i < v.length; i++) {
    risultato[i] = v[i] * 2;
  }
  return risultato;                             // restituito: v non è toccato
}

let a = [1, 2, 3];
console.log(raddoppia(a));                      // [ 2, 4, 6 ]
console.log(a);                                 // [ 1, 2, 3 ]

Esercizio 5

Ciascun programma ha un problema. Dite cosa succede quando lo si esegue (errore? risultato strano?), e correggetelo.

A. Vogliamo stampare tutti gli elementi.

let v = [4, 5, 6];
for (let i = 0; i <= v.length; i++) {
  console.log(v[i]);
}

B. Vogliamo la somma degli elementi.

let v = [4, 5, 6];
let s = 0;
for (let i = 0; i < v.length(); i++) {
  s = s + v[i];
}
console.log(s);

C. Vogliamo l'ultimo elemento.

let v = [4, 5, 6];
console.log(v[v.length]);

D. Vogliamo sommare 1 a ogni elemento.

let v = [4, 5, 6];
for (let i = 0; i < v.length; i++) {
  v + 1;
}
console.log(v);

E. Vogliamo stampare la somma di tutti gli elementi di v.

function somma(v) {
  let s = 0;
  for (let i = 0; i < v.length; i++) {
    let s = s + v[i];
  }
  return s;
}
console.log(somma([4, 5, 6]));
