Esercizio 1

Dieci domande di ripasso. Rispondete senza eseguire il codice.

1. Quale di queste righe provoca un errore?

  • a) let x = 1; x = 2;
  • b) const y = 1; y = 2;
  • c) let z; z = 3;
  • d) const w = 4; console.log(w);

2. Quale di questi confronti vale false?

  • a) 2 == "2"
  • b) 3 >= 3
  • c) "a" < "b"
  • d) 2 === "2"

3. "Chiedi un dato finché non è valido, con almeno una richiesta". Quale ciclo è il più adatto?

  • a) for
  • b) while
  • c) do ... while
  • d) Nessuno dei tre

4. Perché if (x = 5) è sempre un errore?

  • a) Perché = assegna, non confronta
  • b) Perché 5 non è un booleano
  • c) Perché x dovrebbe essere const
  • d) Perché manca l'else

5. Qual è la differenza tra parametro e argomento di una funzione?

  • a) Il parametro è il valore restituito
  • b) L'argomento sta nella definizione
  • c) Parametro nella definizione, argomento nella chiamata
  • d) Il parametro è sempre un numero

6. Dove è visibile una variabile dichiarata con let nel corpo di un for?

  • a) In tutto il programma
  • b) Solo dentro quel blocco
  • c) Solo dopo la fine del ciclo
  • d) Solo dentro le altre funzioni

7. Una funzione ricorsiva non termina mai. Cosa manca quasi certamente?

  • a) Un parametro
  • b) Il console.log
  • c) Il return
  • d) Il caso base

8. Quale condizione verifica che n sia pari e positivo?

  • a) n % 2 == 0 && n > 0
  • b) n % 2 && n > 0
  • c) n % 2 == 0 || n > 0
  • d) n / 2 == 0 && n > 0

9. while (i < 5) { console.log(i); } con i = 0, mai modificata nel corpo. Cosa succede?

  • a) Stampa 0 1 2 3 4
  • b) Stampa 0 una volta
  • c) Errore di sintassi
  • d) Stampa 0 all'infinito

10. Quale espressione dà il numero 42 a partire dalla stringa "42"?

  • a) Number("42")
  • b) String(42)
  • c) typeof "42"
  • d) "42" + 0

Esercizio 7

A. Cosa stampa questo programma? Tenete traccia del valore della variabile globale x.

let x = 10;

function f(x) {
  x = x + 1;
  return x * 2;
}

function g() {
  let y = x + 1;
  x = y;
  return y;
}

console.log(f(x));
console.log(x);
console.log(g());
console.log(x);
console.log(f(x));

B. Cosa succede eseguendo questo programma?

function conta() {
  let c = 0;
  c++;
}
conta();
console.log(c);

C. Cosa succede eseguendo questo programma?

for (let i = 0; i < 3; i++) {
  console.log(i);
}
console.log("fine:", i);
