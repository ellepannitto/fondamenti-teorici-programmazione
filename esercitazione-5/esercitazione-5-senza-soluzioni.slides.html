Recap 1 · Funzioni ricorsive

Una funzione è ricorsiva quando, nel suo corpo, richiama se stessa. Ogni chiamata lavora su un problema più piccolo, finché il problema diventa così semplice da avere una risposta immediata.

function conto(n) {
  if (n == 0) {                                 // caso base: ci si ferma
    console.log("Via!");
  } else {                                      // passo ricorsivo: la funzione richiama se stessa
    console.log(n);
    conto(n - 1);                               // con un valore più piccolo
  }
}

conto(5);                                       // stampa: 5 4 3 2 1 Via!

Il problema che conto(5) risolve contiene una copia più piccola di se stesso: l'output 5 4 3 2 1 Via! è 5 seguito dall'output di conto(4), cioè 4 3 2 1 Via!; questo a sua volta è 4 seguito dall'output di conto(3), e così via fino a conto(0), che stampa solo Via!. Come scatole una dentro l'altra:

Una funzione ricorsiva ha sempre due parti:

  • il caso base: il caso più semplice, in cui la risposta è immediata e non si richiama la funzione;
  • il passo ricorsivo: la funzione si richiama su un valore che si avvicina al caso base (qui n - 1).

Ogni chiamata ha le proprie variabili: il n della chiamata conto(5) è diverso dal n della chiamata conto(4). Le chiamate restano "in attesa" una dentro l'altra, e ritornano in ordine inverso: l'ultima chiamata (quella del caso base) finisce per prima.

Per fattoriale(3) (che vedremo nell'esercizio 3), ecco come le chiamate si aprono e si chiudono:

Per questo conta dove si scrive un'istruzione rispetto alla chiamata ricorsiva: quello che sta prima viene eseguito andando "in giù", quello che sta dopo viene eseguito al ritorno, "in su".

Attenzione: senza caso base, o con un passo che non si avvicina mai al caso base, le chiamate non finiscono più e JavaScript si ferma con l'errore RangeError: Maximum call stack size exceeded.

Recap 2 · Come si scrive una funzione ricorsiva

Per scrivere una funzione ricorsiva ci si pongono sempre le stesse domande:

  1. Caso base: qual è il caso più semplice, in cui so già la risposta senza fare calcoli?
  2. Passo ricorsivo: se conosco la risposta per un problema più piccolo (ad esempio n - 1), come la uso per ottenere la risposta per n?
  3. Fidarsi: nel passo ricorsivo si assume che la chiamata ricorsiva funzioni già. Non serve seguire tutte le chiamate col pensiero, basta che caso base e passo siano giusti.

Un esempio, la somma dei numeri da 1 a n:

  • caso base: somma(0) vale 0;
  • passo: somma(n) è n più la somma dei numeri da 1 a n - 1, cioè n + somma(n - 1).
function somma(n) {
  if (n == 0) {
    return 0;
  }
  return n + somma(n - 1);
}

Spesso la formula del problema è già ricorsiva (fattoriale, somma, ...): in questi casi la funzione si scrive "copiando" la formula. Ricordate il return anche nel passo ricorsivo!

Recap 3 · Variabili locali e globali, scope e shadowing

Lo scope di una variabile è la parte di programma in cui la variabile esiste e si può usare.

  • una variabile dichiarata dentro una funzione (e i suoi parametri) è locale: esiste solo durante la chiamata, e sparisce quando la funzione finisce. È per questo che ogni chiamata ricorsiva ha il proprio n;
  • una variabile dichiarata fuori da ogni funzione è globale: si può leggere e modificare da qualunque punto (ad esempio un contatore dichiarato all'inizio del programma);
  • con let, una variabile esiste solo nel blocco { ... } in cui è dichiarata: anche la i di un for o una variabile dentro un if.

Se una variabile locale ha lo stesso nome di una variabile esterna, la locale oscura (in inglese shadowing) quella esterna: dentro la funzione il nome si riferisce alla locale, e la globale non è raggiungibile e non viene toccata.

let x = 10;                                     // globale

function f() {
  let x = 5;                                    // locale a f: oscura la x globale
  if (x > 0) {
    let x = 99;                                 // locale al blocco: oscura la x di f
    console.log(x);                             // 99
  }
  console.log(x);                               // 5: il blocco è finito
}

f();
console.log(x);                                 // 10: la x globale non è cambiata

Ogni livello (programma, funzione, blocco) ha le sue variabili. Per trovare il significato di x, JavaScript parte dal livello più interno e risale verso l'esterno, fermandosi alla prima x che trova.

Senza il let la situazione è diversa: l'assegnamento modifica la variabile globale.

function g() {
  x = x + 1;                                    // niente let: usa la x globale
}

g();
console.log(x);                                 // 11

Lo stesso vale per i parametri: nella funzione h(x) il parametro x è una variabile locale che oscura la x globale, e cambiarlo non cambia il valore fuori.

function h(x) {
  x = x * 2;
  return x;
}

console.log(h(3), x);                           // 6 11: la x globale è ancora 11

Regole pratiche:

  • si preferiscono le variabili locali e i parametri: la funzione si capisce da sola, senza guardare il resto del programma;
  • evitate di usare per una variabile locale il nome di una globale: funziona, ma è facile confondersi;
  • una variabile globale che una funzione modifica "di nascosto" (come g) rende il programma difficile da seguire: se serve un valore, meglio passarlo come parametro e restituire il risultato con return.

Recap 4 · Cicli annidati

Un ciclo può contenere un altro ciclo. Il ciclo interno viene eseguito per intero a ogni giro del ciclo esterno. Esempio: le prime cinque righe delle tabelline del 2, del 3 e del 4.

for (let i = 2; i <= 4; i++) {          // esterno: una tabellina per giro (2, 3, 4)
  let riga = "";                        // si azzera a ogni giro esterno
  for (let j = 1; j <= 5; j++) {        // interno: 5 giri, ricomincia ogni volta
    riga = riga + (i * j) + " ";
  }
  console.log(riga);                    // una riga per ogni tabellina
}
2 4 6 8 10
3 6 9 12 15
4 8 12 16 20

Il ciclo esterno fa 3 giri (i vale 2, 3, 4); a ognuno, il ciclo interno fa tutti i suoi 5 giri (j da 1 a 5) e costruisce una riga.

  • il corpo del ciclo interno viene eseguito (giri esterni) × (giri interni) volte: qui 3 * 5 = 15;
  • le variabili dei due cicli (i, j) devono avere nomi diversi;
  • le variabili che servono "da capo" a ogni giro esterno (come riga) vanno inizializzate dentro il ciclo esterno, prima del ciclo interno;
  • il numero di giri interni può dipendere dalla variabile del ciclo esterno (ad esempio in un triangolo di asterischi, dove la riga i ne ha i: il ciclo interno va da 1 a i);
  • per seguire un programma a mano, si scrive una tabella con i valori di i e j a ogni giro.
